# CoreBound

A premium fantasy game built around elemental powers, progression, and discovery.

## Tech stack

- React
- TypeScript
- Vite
- CSS

## Getting started

Requirements: Node.js 20.19+ or 22.12+.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Project structure

```
public/
  assets/
    backgrounds/
    elements/
    ui/
src/
  components/
  data/
  styles/
```

## Artwork

Place elemental portraits and icons in `public/assets/elements/`, the title-screen background in `public/assets/backgrounds/`, and interface artwork in `public/assets/ui/`.

The interface currently uses CSS-built placeholder artwork, so it runs before custom images are uploaded.
